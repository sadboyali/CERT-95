# CERT 95 — منصّة التدريب على الأمن الهجومي

مشروعان متكاملان لتعلّم أمن المعلومات بالهجوم العملي، ضمن قصة واحدة: **«عملية الأرشيف الصامت» — القضية MR-024**.

| المجلد | الوصف |
|--------|-------|
| **[`lab/`](lab/)** | 🎯 **المختبر المصاب** — تهاجمه. خادم محلي صفر‑تبعيات، 13 ثغرة مقصودة مرتّبة في خطّ زمني مترابط (كل فصل يفتح الذي يليه) عبر الويب والتشفير والهندسة العكسية والفورنسِك. |
| **[`solutions/`](solutions/)** | 📖 **دليل الحلول** — عرض شرائح يتبع القصة: كل شريحة = حلّ فصل بخطوات مرتّبة، أدوات كالي، الأوامر بالضبط، ثم الفلاگ. |

## البدء السريع

```powershell
# 1) شغّل المختبر (يتطلب Node.js 22.5+ فقط، بلا npm install)
cd lab
node server.js
#    → افتح http://127.0.0.1:4000

# 2) دليل الحلول (عرض شرائح) يفتح مباشرةً بلا خادم:
#    solutions/index.html
```

## الفكرة

- **قصة واحدة من الألف للياء**: تبدأ من بوابة الموقع العامة وتتتبّع أثر المخترق فصلاً بعد فصل حتى خزنته الأخيرة.
- **13 فصلاً مترابطاً**: حلّ الفصل يفتح الذي يليه (تقدّمك محفوظ في المتصفح).
- **تعليمي**: كل فصل فيه قصة + هدف + شرح الثغرة + تلميحات متدرّجة، ورتبة تترقّى معك.
- **دليل حلول شريحة بشريحة**: أدوات كالي + الأوامر الدقيقة + خطوات مرتّبة لكل ثغرة.

## السلامة والنطاق

> كل الثغرات **مقصودة** ومعزولة لغرض التعلّم. البيئة محلية بالكامل وببيانات اصطناعية:
> لا shell حقيقي، لا تنفيذ أوامر على نظامك، لا اتصالات خارجية. حقن الأوامر يستخدم
> صدفة محاكاة، واجتياز المسار محصور داخل مجلد sandbox. **لا توجّه أي تقنية هنا
> إلى نظام لا تملك إذناً خطّياً صريحاً باختباره.**
