# CERT 95 — المختبر المصاب

مختبر تدريبي **محلي ومعزول** بثغرات مقصودة، ضمن قصة واحدة: **«عملية الأرشيف الصامت»**. ثلاثة عشر فصلاً مترابطاً عبر أربعة مجالات (الويب، التشفير، الهندسة العكسية، الفورنسِك) — كل فصل يفتح الذي يليه.

> ⚠️ **تنبيه:** كل ثغرة هنا *مقصودة* للتعلّم فقط. البيئة محلية وببيانات اصطناعية، ولا يوجد أي تنفيذ أوامر حقيقي على نظامك (حقن الأوامر عبر صدفة محاكاة معزولة). لا تستعمل هذا الكود في الإنتاج، ولا توجّه أي تقنية منه إلى نظام لا تملك إذناً صريحاً باختباره.

## التشغيل

المتطلب الوحيد: **Node.js 22.5 أو أحدث** (بلا أي `npm install` — صفر تبعيات).

```powershell
cd lab
node server.js
```

ثم افتح: **http://127.0.0.1:4000**

- لتغيير المنفذ: `PORT=5000 node server.js`
- ملفات التحديات تُولّد تلقائياً في `challenges/` عند أول تشغيل.
- تقدّمك (الفصول المحلولة) يُحفظ في متصفحك (localStorage).

## الحلول

دليل الحلول عرض شرائح شامل (أدوات كالي + الأوامر الدقيقة + خطوات لكل فصل):
افتح `../solutions/index.html`. استعمله **بعد** محاولتك الخاصة.

## البنية

```

│  ├─ flags.js          الفلاگات والبيانات الوصفية (سرّ خادم)
│  ├─ util.js           أدوات مشتركة (ZIP, CRC32, إرسال الردود…)
│  └─ artifacts.js      مولّدات ملفات التحديات (تشفير/عكسية/فورنسِك)
├─ public/              واجهة المختبر (index.html, campaign.js, app.js, app.css, logo.png)

└─ sandbox/             مجلد معزول لتحدي Path Traversal
```
